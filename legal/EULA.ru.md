# TudjixOS — проект лицензионного соглашения с конечным пользователем (EULA)

**Статус: проект, не действующее соглашение.**

## 1. Назначение

Настоящий документ описывает предполагаемые правила использования компонентов TudjixOS, разрабатываемых Tudjix Lab. Перед официальным применением необходимо указать полное наименование правообладателя и применимое право.

## 2. Редакции

- **Free:** планируется бесплатная самостоятельная редакция без ограничения срока использования, с функциональными ограничениями редакции.
- **Home:** редакция для личных и семейных серверов; коммерческие условия будут опубликованы отдельно.
- **Enterprise:** редакция для организаций; условия лицензирования и поддержки определяются отдельно.

## 3. Предполагаемые права пользователя

Пользователь сможет устанавливать и использовать соответствующую редакцию на условиях опубликованной для неё лицензии. Конкретные ограничения по устройствам, числу пользователей, переносу лицензий и коммерческому использованию ещё не утверждены.

## 4. Безопасность и ответственность

Администратор сервера отвечает за настройку доступа, резервное копирование и соблюдение законодательства при использовании своих сервисов. Объём гарантий, ограничений ответственности и обязательств по поддержке требует юридической проработки и не устанавливается настоящим черновиком.

## 5. Стороннее программное обеспечение

TudjixOS основана на Debian и может включать компоненты под GPL, LGPL, MIT, Apache и другими лицензиями. Их права и условия не отменяются настоящим документом. Для соответствующих компонентов должны предоставляться необходимые уведомления, тексты лицензий и исходный код либо надлежащий способ его получения.

## 6. Изменения

Окончательная редакция EULA будет опубликована до начала распространения продуктов, для которых требуется отдельное пользовательское соглашение.
