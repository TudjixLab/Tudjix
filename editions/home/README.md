# Tudjix Home и HomeN — архитектура редакций

> Статус: проектная спецификация для TudjixOS 0.1 Alpha. Описанные возможности запланированы и не означают, что они уже реализованы.

## Общее устройство

**Tudjix Home** — редакция для домашнего сервера, семейного NAS и локальных сервисов. **Tudjix HomeN** — OEM-вариант той же редакции для NAS, поставляемых партнёрами-производителями. HomeN наследует функциональность Home, но использует аппаратные профили производителя и иной порядок активации лицензии. Это не самостоятельная кодовая база и не отдельная розничная редакция.

Общие компоненты: Tudjix Core, Tudjix Kernel, System Manager (администрирование), Portal (пользователи), Private/Common-хранилища, SMB/NFS, резервное копирование, автоматические обновления, виртуальные машины и контейнеры, приложения, Selective Gateway и Print & Scan Server. SSH сохраняется для профессионального администрирования.

## Различия Home и HomeN

| Характеристика | Home | HomeN |
| --- | --- | --- |
| Назначение | Установка владельцем на совместимый сервер/ПК/NAS | Предустановка производителем NAS |
| Распространение | Отдельная платная бессрочная лицензия | OEM-лицензия через партнёра |
| Функциональность Home | Полная | Полная, с OEM-интеграциями |
| Архитектуры | AMD64/x86-64 и ARM64/AArch64, на поддерживаемом оборудовании | AMD64/ARM64 в зависимости от конкретной модели NAS |
| Аппаратная совместимость | Универсальные драйверы и проверенные профили | Проверенный профиль модели, firmware и драйверы производителя |
| Активация | Ключ, выдаваемый Tudjix Lab | Заводская/OEM-активация |

| Обновления | Проверенные обновления Home | Проверенные обновления с учётом OEM-профиля |
| Управление USB-МФУ | Да | Да |
| Selective Gateway | Да | Да |

### Лицензирование

Home приобретается бессрочно (не подписка). Изначальная активация не считается переносом: допускаются три последующих переноса на другие серверы. Повторная установка на том же оборудовании перенос не расходует. В System Manager показываются состояние лицензии и оставшиеся переносы. Первоначально выдача ключей по электронной почте и регистрация на сервере лицензий Tudjix Lab выполняются вручную.

HomeN не продаётся отдельно от совместимого OEM-устройства; лицензия закреплена за конкретным NAS. Самостоятельный перенос на другое устройство невозможен. Авторизованный ремонт или замена устройства рассматриваются отдельно.

Проверка лицензии основана на криптографически подписанных данных с локальной верификацией и периодической онлайн-проверкой с льготным офлайн-периодом. После подтверждённой недействительности лицензии и завершения льготного периода редакция при следующей перезагрузке переходит в Free без переустановки и удаления пользовательских данных. Отключение платных функций должно быть безопасным для данных, работающих VM и контейнеров; поведение учётных записей сверх лимита Free требует отдельной спецификации. Включение будущих крупных версий в бессрочную лицензию пока не определено.

## Tudjix Kernel и поддержка оборудования

Tudjix Kernel собирается из исходников поддерживаемой LTS-ветки Linux с отдельными конфигурациями и пакетами для **amd64 (Intel/AMD)** и **arm64 (в том числе совместимые устройства Qualcomm)**. Общая кодовая база, модульные драйверы и отдельные аппаратные профили. Совместимость ARM64 с конкретным устройством требует проверки загрузчика, firmware, ACPI/Device Tree и драйверов. OpenZFS — отдельно собираемый совместимый модуль, не часть upstream-ядра.

Базовые подсистемы: NVMe/SATA/SCSI/USB Storage, EXT4/XFS/Btrfs, RAID/LVM/dm-crypt, Ethernet/IPv4/IPv6, VLAN/bridge/bonding, nftables/conntrack/NAT/NFQUEUE, KVM/VirtIO/VFIO/IOMMU, namespaces/cgroups v2/OverlayFS, UEFI/EFI/initramfs, TPM/криптография/AppArmor/seccomp, подпись модулей и диагностика. Для USB-МФУ — USB Host, xHCI/EHCI и необходимые контроллеры, libusb и при необходимости usblp. Конкретные параметры Kconfig проверяются по выбранной версии ядра.

## Скрытый Tudjix Driver Manager

Driver Manager — **внутренний компонент Tudjix Core** для обнаружения и установки совместимых драйверов. В System Manager **нет отдельного раздела «Драйверы»**. Пользователю не показываются VID/PID, подбор пакетов, CUPS/SANE и другие внутренние этапы. Подробные логи доступны администраторам для диагностики через SSH.

Автоматический сценарий:
1. Подключение USB-МФУ; udev/sysfs определяет VID/PID, интерфейсы и дескрипторы.
2. Поиск подходящих компонентов в локальном каталоге, затем в доверенных каталогах и репозиториях.
3. Автоматическая установка проверенных совместимых пакетов для amd64 или arm64, без ручного подтверждения.
4. Инициализация печати и сканирования; проверка реально работающих функций.
5. Уведомление в **System Manager → Устройства → Принтеры и сканеры**: МФУ готово к настройке. Пользователь выбирает сетевую печать, сетевое сканирование, обнаружение в LAN и права доступа.

Только подтверждённые функции показываются как доступные. Возможны отдельные драйверы для печати и сканирования. Если подходящий драйвер не найден или функция не работает, система показывает понятное состояние ошибки, а не ложную готовность. Нельзя автоматически выполнять непроверенные сторонние установщики. При неудачной установке предусматриваются восстановление конфигурации и журнал диагностики.

### Print & Scan Server

Модуль Home/HomeN предоставляет сетевую печать через CUPS/IPP и обнаружение через mDNS/Avahi, а также сканирование через SANE и совместимые сетевые протоколы (например, eSCL) при наличии поддержки. Печать и сканирование на Windows, Linux, macOS и мобильных устройствах зависят от совместимости конкретного клиента и МФУ. Сетевой доступ по умолчанию ограничен доверенной LAN; публикация в интернет не выполняется.

## Selective Gateway

Home и HomeN позволяют вручную назначить Tudjix сервер шлюзом для выбранного устройства (например, Smart TV). Обычный трафик перенаправляется к основному маршрутизатору без модификации DPI, а трафик выбранных пользователем доменов/сервисов обрабатывается средствами zapret. Настройки хранятся в **System Manager → Сеть → Selective Gateway → Сайты и сервисы**. Функция не является VPN и не гарантирует обход любых ограничений; необходима корректная работа IPv4/IPv6, DNS, маршрутизации и NAT.
